# 길로로 인스타그램 카드뉴스

원고(기사·자료·메모)를 받아 1080×1350 카드뉴스로 만든다.
가이드라인 파일에서 좌표·폰트·컬러를 실측한 수치이므로 **눈대중으로 바꾸지 않는다.**

## 전제

Figma MCP가 연결되어 있어야 한다. 없으면 `npx @figma/mcp` 계열 설정을 먼저 안내한다.
`use_figma` 호출 전에는 항상 `figma-use` 스킬(또는 `skill://figma/figma-use/SKILL.md`)을 먼저 읽는다.

**가이드 파일은 필수가 아니다.** 커버와 피드는 아래 실측 스펙만으로 코드로 완성된다.
**엔딩만 예외** — 길로로 프로필이 이미지 에셋이라 코드로 만들 수 없다.
작업할 파일 안에 있는 기존 엔딩 프레임(이름에 `엔딩` 또는 회차명이 붙은 1080×1350)을 찾아 복제하고,
없으면 사용자에게 엔딩 프레임을 그 파일에 올려달라고 요청한다.

## 파일 스타일을 쓴다

가이드 파일에 스타일이 정의돼 있다. **수치를 직접 때려넣지 말고 스타일을 먼저 찾아 붙인다.**

| 텍스트 스타일 | 스펙 |
|---|---|
| `길로로 피드 커버 제목` | 80 / Auto |
| `길로로 피드 커버 부제` | 44 / Auto |
| `길로로 피드 본문` | 36 / 170 |
| `길로로 피드 28pt` | 28 / 170 (핸들·마지막장 푸터) |

| 색상 스타일 | 용도 |
|---|---|
| `화이트 그라디언트 배경` | 밝은 배경용 |
| `하단 블랙 오파시티` | 커버 하단 어둡게 (기본) |
| `하단 흰색 오파시티` | 밝은 이미지 위에 쓰는 반전 버전 |

스타일이 없거나 외부 라이브러리로 연결돼 있으면(`getLocalTextStylesAsync()`에 안 잡힘)
아래 표의 폰트·크기·행간을 직접 지정한다. 결과는 같다.

## 작업 순서

1. **원고 정리** — 받은 내용을 커버 1장 + 피드 n장 + 마지막장 1장으로 나눈다.
   피드는 보통 5~8장. 장별 한 문장(최대 3줄)으로 압축한다.
2. **구성안 확인** — 장 순서와 각 장 문구를 먼저 사용자에게 보여주고 확인받는다.
   **확인 없이 Figma에 그리지 않는다.**
3. **카드 생성** — 커버·피드는 아래 스펙대로 직접 만든다.
   엔딩은 같은 파일의 기존 엔딩 프레임을 `clone()`한다.
4. **이미지 배치** — 아래 이미지 규칙을 따른다.
5. **문구 입력** — 폰트 교체 함정(아래)을 반드시 처리한다.
6. **검증** — 데드존·줄 수·위치 고정을 확인한다.

## 카드 규격 — 1080 × 1350 (4:5)

### 커버
| 요소 | 스펙 |
|---|---|
| 하단 그라디언트 | 1080×583 @ y767. LINEAR, `#414141` a0 → a0.8, **blendMode MULTIPLY**, 위→아래 |
| 제목 그리드 | x115.5, 849 FIXED · VERTICAL · gap 10 · HUG |
| 부제 | Pretendard **Bold 44**, LH auto, 흰색 |
| 제목 | Pretendard **Bold 80**, LH auto, 흰색, **최대 2줄** |
| 그리드 y | **2줄 903 / 1줄 979** — 하단 정렬 기준이므로 **위치 변경 금지** |
| 핸들 | `@gilroro.mag` · **ABeeZee Regular 28** · LH 170% · 흰색 · x448 y1232 |

### 피드
| 요소 | 스펙 |
|---|---|
| 말풍선 | 흰 배경 · **R16** · **검정 스트로크 2** · 패딩 20/30 · gap 10 · **HUG** |
| 위치 | **x85 y1074 고정** — 폭·높이만 가변 |
| 본문 | Pretendard **SemiBold 36** · **LH 170%** · 검정 · **최대 3줄** |

### 마지막장
| 요소 | 스펙 |

| 프로필 | 580×135 · x250 y680 · R24 (까마귀 ver **R36**) · 최신형은 **흰 카드 + 원형 프로필 + `gilroro.mag` / `길로로` 2줄** |

## 고정 규칙

- **마지막장 배경은 앞장 이미지를 재사용**하고, 가독성에 맞춰 오파시티만 조절한다.
  **엔딩 프레임을 복제해 쓰더라도 배경만은 그 회차 앞장 이미지로 반드시 교체한다** —
  복제본에 남아 있는 이전 회차 배경을 그대로 두면 안 된다. 리드·프로필·푸터만 물려받는다.
- 도형 라운드는 **16**, 스트로크는 **2pt**. 상황에 따라 달라져도 되지만 되도록 이 값.
- 하늘색 `#22CCFF` 박스는 **데드존 표시**다. 실제 카드에 넣지 않는다.
  인스타 UI에 가려지는 영역이므로 그 안에 글자를 두지 않는다.
- 커버 제목은 2줄을 넘기지 않는다. 넘치면 제목을 줄이지 그리드를 옮기지 않는다.
- 피드 본문은 3줄을 넘기지 않는다. 넘치면 장을 쪼갠다.

## 이미지 규칙

원본 비율에 따라 처리가 갈린다.

- **4:5에 가까움**(예: 1200×1500) → 그냥 풀블리드로 채운다.
- **16:9 등 가로로 김**(예: 1000×562) → 4:5로 늘리면 2.4배 확대라 뭉갠다.
  같은 이미지를 **1360×1630으로 깔고 `LAYER_BLUR` 64 + 검정 55% 오버레이**,
  그 위에 **원본 비율 1080×608 밴드를 y371에 얹는다.** 시네마틱하게 읽힌다.

## 함정

⚠️ **폰트** — 가이드 파일의 텍스트 스타일은 `Pretendard Variable`인데 로컬에 없는 경우가 많다.
클론한 텍스트는 그대로 `characters`를 못 바꾼다 (`Cannot write to node with unloaded font`).

```js
await figma.loadFontAsync({family:'Pretendard', style:'Bold'});
t.fontName = {family:'Pretendard', style:'Bold'};  // 먼저 갈아끼운 뒤
t.characters = '제목';                              // 그 다음 문자 대입
```
스타일 링크는 끊기지만 크기·행간은 위 표대로 직접 지정하면 된다.
`@gilroro.mag`와 마지막장 푸터는 **ABeeZee**라 별도로 로드한다.

⚠️ **말풍선은 HUG**다. 폭을 FIXED로 만지면 위치가 틀어진다. 문구만 바꾸고 x·y는 건드리지 않는다.

⚠️ **커버 제목 그리드 y를 자동 계산하지 않는다.** 2줄이면 903, 1줄이면 979 두 값뿐이다.

## 검증 체크리스트

- [ ] 모든 카드 1080×1350
- [ ] 커버 제목 2줄 이내 · 그리드 y가 903 또는 979
- [ ] 피드 본문 3줄 이내 · 말풍선 x85 y1074
- [ ] 데드존(하늘색 영역)에 글자 없음 · 데드존 박스는 결과물에서 제거
- [ ] 마지막장 배경이 앞장 이미지 재사용
- [ ] 핸들·푸터 폰트가 ABeeZee
- [ ] 텍스트 폰트가 전부 로드 가능한 패밀리로 교체됨
